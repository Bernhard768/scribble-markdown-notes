# Scribble.md 📝

A minimal, distraction-free, live-rendering Markdown editor built using vanilla HTML, CSS, and JavaScript. 

## 🚀 Features
* **Live Preview:** See your Markdown render instantly side-by-side as you type.
* **Local File Saving:** Download your notes directly to your computer as `.md` files.
* **Theme Toggle:** Switch between a sleek, high-contrast dark theme and a clean light theme.
* **Lightweight:** Powered by `Marked.js` via CDN, requiring zero installation.

## 🛠️ Built With
* HTML5
* CSS3 (Custom properties & Flexbox)
* JavaScript (Vanilla ES6+)
* [Marked.js](https://github.com/markedjs/marked) - Markdown Parser
